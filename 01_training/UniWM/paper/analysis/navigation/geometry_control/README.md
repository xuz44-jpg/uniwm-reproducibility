# Paired-zero 几何非不变性：CPU 解析校准

**这是数学控制，不是新增模型实验，也不是光流估计器验收。** 本目录没有调用世界模型、RAFT、SIFT、Habitat 渲染或 GPU，没有训练或增加位置。原冻结协议、指标阈值及旧结果均未修改。

## 复算

在本目录运行（Python 3、NumPy）：

```bash
python3 run_geometry_controls.py --inputs . --output output/geometry-recomputed
```

`input_snapshot.json` 和 `input_masks.npz` 保存相机内参、冻结门槛、真实参考布尔掩码及来源哈希。

此模式检查掩码归档和校准脚本身份，然后从快照计算；原文件身份记录保留，但无法代替重新取得原文件核验。`recompute_verification.json` 记录本次从可移植快照独立执行与主输出的逐行CSV及汇总一致性。

文件：`analytic_controls.csv` 是逐条件结果，`analytic_controls.json` 是完整定义、限制、汇总及自动检查，`paper_geometry_note.tex` 是可选论文段落。原12位置、6个查询角度、4个已知漂移、6种已知响应，合计 **1728个解析条件**；两种掩码口径各一行，共3456行，不能当作新增独立样本或场景。

## 构造与公式

相机原生640×480、水平视场90°，按既有像素中心约定缩为256×256后：

\[
K=\begin{bmatrix}128&0&127.5\\0&170.666672&127.5\\0&0&1\end{bmatrix}.
\]

令 \(h_\theta(p)=\pi(KR_y(\theta)K^{-1}\bar p)\)。正负号与现有相机轴约定一致。查询 \(a\in\{\pm3,\pm5,\pm7\}^\circ\)，共同基准漂移 \(b\in\{0,5,10,15\}^\circ\)，**角度响应倍率** \(g\in\{0,-1,0.2,0.5,1,2\}\)。构造零动作端点为 \(h_b(p)\)，动作端点为 \(h_{b+ga}(p)\)。这里的端点是数值投影，不是合成或生成图像。

原配对像素效果及参考为：

\[
\hat D_{a,b,g}(p)=h_{b+ga}(p)-h_b(p),\qquad D_a(p)=h_a(p)-p.
\]

计算它们的 EPE、像素投影增益和原冻结正/负投影规则。**角度倍率 \(g\) 不等于像素 `projected_gain`**；后者受投影、漂移、位置与支持区域影响。已知相对转角 \(ga\) 和角度误差 \(|(g-1)a|\) 来自构造，不是从图像估计得到的新物理测量。

## 两种共同可见口径

1. `within_condition_common_visible`：原参考掩码与 \(h_0,h_a,h_b,h_{b+ga}\) 正深度及图内可见区域相交。边界沿用原实现 `[1,255)`。每行报告保留像素数及相对原掩码的保持率。
2. `matched_across_all_drifts_and_responses`：同一位置与查询角度，对全部漂移和响应条件先取共同可见交集，再用于每一条件。各位置/角度的掩码在全部条件间不变，可避免条件间区域改变混淆。本口径平均保留原掩码 **69.10%**，不因任何生成图结果选像素。

解析可见性不等于生成对应可靠性。本实验没有添加或伪造前后向光流有效性验证；分类仅说明在无估计误差的解析向量上，旧符号/幅度门槛会如何响应。

## 核心结果

正确相对yaw（\(g=1\)），各行对12位置×6角度的72个**条件均值等权平均**：

| 共同漂移 | 每条件共同可见 EPE px | 平均保留率 | 跨全部条件固定共同掩码 EPE px |
|---|---:|---:|---:|
| 0° | 0.000 | 100.00% | 0.000 |
| 5° | 1.197 | 96.63% | 0.865 |
| 10° | 2.223 | 88.50% | 1.705 |
| 15° | 3.056 | 79.61% | 2.594 |

全部相对转角都正确，仍有非零配对像素 EPE；固定共同掩码后的结果也如此。因此不完全由条件间掩码变化造成。

此前沟通的数值例单独保存在 `communicated_example`：仅取 \(b=10^\circ,a=\pm5^\circ,g=1\)，12位置共24条件。每条件共同可见口径的平均 EPE 为 **2.236554824 px**，平均保留88.53%，逐条件1.793–2.909 px。它和上表使用六角度的2.223 px分母不同，不应混用。

**推荐正文数例**在 `recommended_matched_example`：同样是 \(b=10^\circ,a=\pm5^\circ,g=1\) 的24条件，但使用跨全部漂移与倍率固定的共同掩码，平均 EPE 为 **1.742255163 px**，平均保留原参考共同掩码像素的 **69.17%**（不是全图或纹理掩码分母），逐条件1.281–2.291 px。对同一位置与查询角度，所有控制用同一掩码；不同位置、不同查询角度之间不强求同一像素集合。

在 \(b=0\) 的72条件中，零响应全部判近零，反向响应全部判反向；0.2倍、0.5倍和2倍角度响应全部通过正投影规则。三者平均像素投影增益分别约0.199、0.498、2.017。**正投影通过不能验证角度或幅度准确。** 所有漂移和两种支持口径下，这三种正角度倍率均通过该规则，详见JSON。

## 相对映射与解释边界

若 \(\psi_0=h_b,\psi_a=h_{b+ga}\)，同轴纯yaw满足

\[
\psi_a\circ\psi_0^{-1}=h_{ga},\qquad
h_{b+ga}(p)=h_{ga}(h_b(p)).
\]

自动检查的最大数值残差约 \(2.84\times10^{-13}\) px。\(g=1\) 时，比较动作端点与 \(h_a(h_b(p))\) 得零残差。这只是已知同轴旋转的数学一致性，不是验收了生成图上的相对旋转估计器。

一般3D旋转不能直接相加或任意交换。相对矩阵 \(R_aR_0^{-1}\) 的解释依赖坐标与乘法侧：若 \(R_a=AB,R_0=B\)，得到 \(A\)；若 \(R_a=BA\)，得到 \(BAB^{-1}\)。脚本用不同轴旋转的非零交换子检查，防止把当前同轴恒等式推广成任意旋转都能按标量相减。一般SE(3)还涉及相对平移、深度、尺度与可见性。

**允许的结论：**旧paired-zero EPE衡量固定像素端点的效果差；它通常不具共同yaw漂移不变性，不能直接视为相对yaw误差。

**不允许的结论：**这不证明现有NWM误差变化全部来自此效应，不能把解析EPE从模型EPE中扣除，也没有证明任何生成图的角度准确。真实生成漂移可能包含平移、形变和对应失败，需要另外检查支持集与相对几何适用性。原始EPE仍可保留为图像空间诊断。
